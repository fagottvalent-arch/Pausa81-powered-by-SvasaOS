# Sama Vritti Pranayama

PWA di respirazione guidata (Sama Vritti / "respirazione a onde uguali") costruita con **React + Vite + TailwindCSS**.

- Cerchio fluttuante di 8 ellissi SVG intrecciate, una per ogni colore dell'arcobaleno
- 3 cicli × 4 fasi da 5 s: Inspira → Trattieni → Espira → Trattieni (totale 60 s)
- Installabile come PWA (vite-plugin-pwa, manifest, service worker, icone 192/512)

## Avvio

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
